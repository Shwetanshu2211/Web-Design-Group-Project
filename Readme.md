# Fusion Furnish

### Overview

Today's demand for online shopping continues to increase in today's digital world, and furniture is no exception. As consumers flourish in convenience and personalization, the concept of an e-commerce platform dedicated to selling and customizing furniture is now arguably most relevant. The project seeks to set up an easy-to-use, multifunctional website offering customers not only a rich variety of quality furniture, but also the possibility to personalize their pieces with aspects such as color and size. By combining convenience and customization, this platform will offer a better shopping experience for people with all kinds of tastes and needs..

It will ease the way into furniture shopping by offering an interactive and customized experience. From original pieces to complement the decor to custom designs for unique spaces, this will be a one-stop shop. This will appeal to the style-conscious homeowners and people who need functional and personalized furniture for home or work. It includes features like easy customization tool and simple checkout functionality.

## Bootstrap components used in the code:

1. Grid System (`container-fluid, row, col`):
   Used to create responsive and flexible layouts for the structure.

2. Typography (`h2, h5, p`):
   Used for defining text elements like headings and paragraphs.

3. Forms (`form, form-control, form-group`):
   Provides a clean and responsive structure for form inputs, wrapping form elements in groups for styling.

4. Buttons (`btn, btn-custom, btn-outline-dark, btn-link`):
   Styled button components used for interactive elements (like submitting forms or navigating between pages).

5. Text Alignment Utilities (`text-center, text-left, text-right`):
   Used for controlling text alignment within sections.

6. Spacing Utilities (`mb-4, p-4, pt-3`):
   Margin and padding utilities to provide proper spacing between elements.

7. Links (`a` tag):
   Used for hyperlinks, like "Sign Up" or "Sign In" links.

8. Form Validation (Custom error styling):
   Custom classes for displaying error messages for form validation like invalid email or password.

9. Image Styling (`img-fluid`):
   Applied to ensure images are responsive and scale according to their container size.

10. Custom Classes (`btn-custom, login-form, sign-in-image`):
    Custom styling applied for specialized looks and effects (e.g., buttons, images, and form backgrounds).

11. Forms Input Types (`type="email", type="password"`):
    Specified types for input fields to support validation for email and password formats.

12. Flexbox Utilities (`d-flex, justify-content-center, align-items-center`): Used for aligning content and positioning items with flexbox properties for a centered layout.
